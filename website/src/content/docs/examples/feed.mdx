The list ends with a sentinel element carrying `data-on-intersect__once`. When it scrolls into view it requests the next page; the server appends the items to the list and **morphs the sentinel** into one that points at the following page (a changed attribute remounts the directive, so the observer arms again). On the last page the sentinel becomes a plain message.

<Demo title="Live" app source={src}><Feed /></Demo>

## What it uses

- `data-on-intersect__once` on a sentinel; remounting by attribute change rather than replacing the element
- two `patchElements` in one `sse()` response: an `append` into `#feed` and a morph of `#feed-sentinel` by id
- `data-indicator:loading` scoped to the sentinel
- `@intl('RelativeTimeFormat', …)` for the timestamps, evaluated on the client
