<div data-signals="{ count: 0 }" class="row">
  <button data-on:click="$count--">−</button>
  <b data-text="$count"></b>

</div>

<CardGrid>
  <Card title="Attributes, not components" icon="document">
    Behaviour lives in `data-*` attributes on the HTML your server already renders. Expressions are plain JavaScript with `$signals`.
  </Card>
  <Card title="Server in charge" icon="rocket">
    `@get`, `@post` and friends send your signals and apply whatever comes back: HTML morphed by id, JSON merged as signals, or a stream of patches.
  </Card>
  <Card title="Pay for what you use" icon="setting">
    A 4.5 KB core and forty opt-in plugins. The minimal preset is 5.2 KB gzipped; everything, including a streaming client and DOM morph, is 12.2 KB, or 11.6 KB as the shipped standalone file.
  </Card>
  <Card title="Nothing else in the bundle" icon="approve-check">
    No runtime dependencies. A DOM-free core with Node tests, a browser suite, and a strict-CSP mode.
  </Card>
</CardGrid>
