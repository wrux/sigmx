Turn same-origin links and forms into morphed navigations (htmx's hx-boost). Clicking a link fetches the page with `@get`, submitting a form sends it with `@post` or `@get`, and the full-document response is morphed into the current page: `<head>` and `<body>` update in place, elements with matching ids keep their state, a history entry is pushed and the window scrolls to the top.

## Syntax

```html
<body data-boost>
<nav data-boost>…</nav>
```

| part | |
|---|---|
| key | forbidden |
| value | forbidden |

  </table>

Left to the browser: links with `target` or `download`, clicks with a modifier key or a non-primary button, other origins, hash-only changes on the current page, and forms with a `target`.

## Typical page

```html
<body data-boost>
  <nav><a href="/">Home</a> <a href="/about">About</a></nav>
  <main id="main">…</main>
  <audio id="player" controls src="/song.mp3"></audio>
</body>
```

Because the morph keeps elements by id, `#player` keeps playing across navigations and an open menu stays open. Put ids on the parts of the layout that should survive.

## Notes

Needs `httpGet`, `httpPost` and `applyElements` registered (all three are in the `essentials` preset). The server should return a complete HTML document, exactly as for a normal request; the `Sigmx-Request: true` header tells it the request came from sigmx if it wants to skip work. Form submissions respect `novalidate` and the browser's validity checks before sending.

## Register

```ts
import { boost } from 'sigmx/plugins'
```
