Set the `view-transition-name` style from an expression.

## Syntax

```html
data-view-transition="'card-' + $id"
```

| part | |
|---|---|
| key | forbidden |
| value | required |

## Example

<Live html={`
<div data-signals="{ big: false }"><div class="box" data-view-transition="'demo-box'" data-style:width="$big ? '8rem' : '3rem'" data-on:click__viewtransition="$big = !$big"></div><p class="muted">click the box</p></div>
`} />

## Notes

Pair it with `__viewtransition` on `data-on`, or with `useViewTransition` on server patches, to animate between states.

## Register

```ts
import { viewTransition } from 'sigmx/plugins'
```
