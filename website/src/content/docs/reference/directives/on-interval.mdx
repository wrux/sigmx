Run an expression on a timer.

## Syntax

```html
data-on-interval="$ticks++"
data-on-interval__duration.5s="@get('/status')"
```

| part | |
|---|---|
| key | forbidden |
| value | required |

## Modifiers

| modifier | effect |
|---|---|
| `__duration.ms|s` | interval (default 1s) |

## Example

<Live html={`
<div data-signals="{ ticks: 0 }" data-on-interval__duration.500ms="$ticks++">ticks: <b data-text="$ticks"></b></div>
`} />

## Notes

The timer is cleared when the element unmounts.

## Register

```ts
import { onInterval } from 'sigmx/plugins'
```

<Cost name="onInterval" />
