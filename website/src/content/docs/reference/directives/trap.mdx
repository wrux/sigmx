Keep keyboard focus inside a dialog while it is open (Alpine's x-trap).

## Syntax

```html
data-trap="$open"
```

| part | |
|---|---|
| key | forbidden |
| value | required |

## Modifiers

| modifier | effect |
|---|---|

## Example

<Live html={`
<div data-signals="{ open: false }">
  <button data-on:click="$open = true">Open dialog</button>
  <div data-show="$open" data-trap="$open" data-on:keydown__window="evt.key === 'Escape' && ($open = false)" style="display:none;border:2px solid var(--sl-color-accent);border-radius:.5rem;padding:.8rem;margin-top:.5rem">
    <p>Tab cycles between these controls only. Escape closes and focus returns to the button.</p>
    <div class="row"><input placeholder="name"> <button data-on:click="$open = false">Cancel</button> <button data-on:click="$open = false">Save</button></div>
  </div>
</div>
`} />

## Notes

When the expression turns true the first focusable element receives focus and Tab wraps at both ends; when it turns false, focus returns to the element that had it before.
