Set innerHTML from an expression (Alpine's x-html).

## Syntax

```html
data-html="$markup"
```

| part | |
|---|---|
| key | forbidden |
| value | required |

## Example

<Live html={`
<div data-signals="{ markup: '<b>bold</b> and <i>italic</i>' }">
  <input data-bind:markup style="width:100%">
  <p data-html="$markup"></p>
</div>
`} />

## Notes

Only use it with markup you trust; nothing is sanitised. Scripts inside are not executed. For server-rendered fragments prefer `@get` with a morph.

## Register

```ts
import { html } from 'sigmx/plugins'
```
