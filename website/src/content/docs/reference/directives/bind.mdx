Two-way binding between an element's value and a signal.

## Syntax

```html
data-bind:email
data-bind="email"
data-bind:price__event.change
```

| part | |
|---|---|
| key | or value: the signal path |
| value | or key |

## Modifiers

| modifier | effect |
|---|---|
| `__event.name[.name]` | events that write the signal; default depends on the element |
| `__case.*` | key casing |

## Example

<Live html={`
<div data-signals="{ v: { text: '', n: 5, on: true, pick: 'b', many: ['x'] } }">
  <div class="row"><input data-bind:v.text placeholder="text"> <input type="number" data-bind:v.n> <label><input type="checkbox" data-bind:v.on> on</label></div>
  <div class="row"><label><input type="radio" value="a" data-bind:v.pick> a</label><label><input type="radio" value="b" data-bind:v.pick> b</label> <label><input type="checkbox" value="x" data-bind:v.many> x</label><label><input type="checkbox" value="y" data-bind:v.many> y</label></div>
  <pre data-text="JSON.stringify($v)"></pre>
</div>
`} />

## Notes

If the signal does not exist, it is created from the element's current value. See [Forms and binding](/guides/forms/) for the per-element rules: numbers stay numbers, checkbox groups bind to arrays, radios share a name, `select multiple` gives an array, file inputs give base64 file objects.
