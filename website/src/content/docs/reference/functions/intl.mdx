Locale-aware formatting through the `Intl` APIs. The first argument names the `Intl` constructor; the second is the value; the third the constructor's options; the fourth a locale or list of locales. The last two are optional.

## Syntax

```js
@intl('NumberFormat', 1234.5, { style: 'currency', currency: 'EUR' })
@intl('DateTimeFormat', new Date(), { dateStyle: 'long' }, 'de-AT')
@intl('RelativeTimeFormat', [-3, 'day'])          // value is [amount, unit]
@intl('ListFormat', ['a', 'b', 'c'])
@intl('PluralRules', 2)                            // 'one', 'other', …
@intl('DisplayNames', 'fr', { type: 'language' })
```

`NumberFormat`, `DateTimeFormat`, `RelativeTimeFormat` and `ListFormat` call `.format()`, `PluralRules` calls `.select()` and `DisplayNames` calls `.of()`.

  <p class="muted" data-text="@intl('NumberFormat', $amount / 1000000, { style: 'percent', maximumFractionDigits: 1 }, $locale) + ' · ' + @intl('NumberFormat', $amount, { notation: 'compact' }, $locale)"></p>

## Relative time and lists

<Live title="RelativeTimeFormat, ListFormat" html={`
<div data-signals="{ days: -3, items: ['bread', 'milk', 'eggs'], locale: 'en' }">
  <div class="row"><input type="range" min="-10" max="10" data-bind:days> <select data-bind:locale><option>en</option><option>es</option><option>pl</option></select></div>
  <p><b data-text="@intl('RelativeTimeFormat', [$days, 'day'], { numeric: 'auto' }, $locale)"></b> · <span data-text="@intl('ListFormat', $items, { type: 'conjunction' }, $locale)"></span></p>
</div>
`} />

## Plural rules and display names

Pick the right word form without an if-chain, and show language or region names in the user's language.

<Live title="PluralRules, DisplayNames" html={`
<div data-signals="{ n: 1, code: 'fr', locale: 'en' }">
  <div class="row"><input type="number" min="0" data-bind:n style="width:4rem"> <select data-bind:code><option>fr</option><option>de</option><option>ja</option></select> <select data-bind:locale><option>en</option><option>fr</option><option>de</option></select></div>
  <p><b data-text="$n + ' ' + ({ one: 'item', other: 'items' })[@intl('PluralRules', $n, undefined, $locale)]"></b> · <span data-text="@intl('DisplayNames', $code, { type: 'language' }, $locale)"></span></p>
</div>
`} />

## Notes

An unknown constructor name is reported as an error. Formatters are created per call; for hot loops, format on the server or cache in a signal.

## Register

```ts
import { intl } from 'sigmx/plugins'
```
