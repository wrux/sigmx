# Notices

sigmx is an independent implementation. Its `data-*` attribute syntax and modifier scheme are
compatible with the public API of Datastar (https://data-star.dev) so that existing markup can be
migrated, and the project was started by studying that library. It contains no code from Datastar
or Datastar Pro: the reactive graph, signal store, expression compiler, engine and every plugin
were written from scratch against the documented behaviour.
